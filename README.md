Disease Outcome Prediction Using Genetic and Clinical Data
Overview
This project uses machine learning to predict whether a tumor is Malignant (M) or Benign (B) based on genetic and clinical data.
X---X---X---X---X 
Steps to Use
- Upload the dataset: Use 3. Predict Disease Outcome Based on Genetic and Clinical Data.csv.
- Run the Python code: The program preprocesses the data, trains a RandomForestClassifier, evaluates its accuracy, and visualizes the confusion matrix.
  
  Tools-
- Language: Python
- Libraries:- pandas for data handling
- scikit-learn for machine learning
- matplotlib and seaborn for visualization
- 
  Output-
- Classification accuracy.
- Confusion matrix heatmap.
